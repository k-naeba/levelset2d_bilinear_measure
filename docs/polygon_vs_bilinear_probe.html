levelset2d_polygon · single grid cell · all 16 MarchCell cases

Sweeping a measurement line across one cell

One 2×2 level-set cell, all four corner values independently adjustable. A horizontal probe line scans from y = 0 to y = 1. At each height we compare where the extracted polygon's edge crosses the probe against where the raw bilinear field itself crosses zero. Every corner-sign combination runs through the same MarchCell switch levelset2d_polygon itself uses (all 16 cases, not just the saddle) -- including, for the two ambiguous saddle cases (5 and 10), the true cell-center-value disambiguation. That's why, unlike the 3D marching-cubes case, the two methods here never disagree on whether there's a crossing, only on where it is, no matter how the four corners are set.

Move the probe line

Drag each corner slider to set that corner's level-set value (negative = inside, positive = outside); drag the probe slider to move the horizontal probe from the bottom edge to the top edge. The polygon (blue) is whichever straight segment(s) -- zero, one, or two, depending on which of MarchCell's 16 cases the current corner signs land on -- levelset2d_polygon's MarchCell actually emits for this configuration; the field behind it is the true bilinear value, colored blue (inside) to red (outside).
